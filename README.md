# revisar-app

Skill para Claude Code que revisa **cualquier app o web**, antes o después de lanzarla, en tres frentes:

- **Costes:** facturas sorpresa, límites de gasto y bucles infinitos.
- **Seguridad:** RLS, claves expuestas, IDOR, autenticación, webhooks y WordPress.
- **Legal (España/UE):** LSSI, RGPD, cookies, accesibilidad (Ley 11/2023), comercio electrónico, IA y tiendas de apps.

Genera un informe con evidencias y gravedad (🔴 🟠 🟡) y no toca nada sin tu OK.

## Instalar

```bash
git clone https://github.com/PeriCod4/revisar-app ~/.claude/skills/revisar-app
```

## Usar

Abre Claude Code en la carpeta de la app y escribe:

```
/revisar-app
```

¿No usas Claude Code? Copia el contenido de [`SKILL.md`](SKILL.md) como prompt en cualquier asistente de IA.

## Aviso

Es una lista de comprobación orientativa y no sustituye el asesoramiento jurídico. Las normas, fechas e importes cambian, así que verifica lo que dependa de ellos.
